Коллеги, добрый день.

Короткое обновление по Diadoc-пакетам и форматированию кода.

1. Пакеты Diadoc теперь перенесены в `ws` как локальные таблицы:

- `diadoc_packet`
- `diadoc_packet_document`
- `diadoc_packet_doc_operation`

Их можно использовать локально в новых задачах, особенно если нужны фильтры, join-ы с локальными таблицами `rvk-ws` или другая логика, которую неудобно или невозможно делать через REST DataStore и ограничения удаленной базы.

Текущую реализацию, где данные уже берутся удаленно из Diadoc, специально переделывать не нужно. Если в будущих задачах появятся ограничения из-за REST/удаленной БД, тогда можно будет точечно переводить такие места на локальные таблицы.

Сейчас данные по пакетам продолжают нарабатываться в проекте Diadoc: XML разбирается там, нужные поля раскладываются в нормальный вид, а затем уже подготовленные данные синхронизируются в `ws`. В основном проекте нужно использовать данные из пакета уже разобранными и нормализованными, без повторного парсинга XML на стороне `ws`.

Часть данных уже вынесена в отдельные колонки, остальные данные сохраняются в `extra_data`.

Если для новых задач потребуется достать дополнительные данные из XML, это нужно делать на стороне проекта Diadoc: добавить разбор XML и разложить данные в нужные поля там. После этого данные будут перекачиваться в `ws`, и в основном проекте можно будет использовать уже нормальные локальные данные.

2. В проекте подключено стандартное форматирование кода через Spotless.

Перед созданием MR просьба выполнить из корня репозитория:

```bash
./gradlew spotlessApply
```
