Основа дизайна — существующий Lit-компонент; полный редизайн не требуется. Достоверность applied state и основной CRUD — до пилота.

## F07.1. Основная панель

- [x] В свёрнутом состоянии видны поиск (если настроен), кнопка условий, компактные chips **применённых** условий и действие сброса. Показывать максимум 3 chips и «+N», полный список доступен при раскрытии.
- [x] В раскрытой панели — редактор draft, «Добавить условие», «Найти», «Сбросить», пресеты. Draft отличается от applied индикатором «Есть неприменённые изменения».
- [x] Выбор сохранённого фильтра только заполняет draft. Пользователь понимает, что таблица изменится после «Найти». Применение при выборе не включать автоматически.
- [x] Сохранение не применять к таблице побочным эффектом. Разделить «Сохранить изменения» и «Сохранить как новый»; первое доступно для выбранного редактируемого preset.
- [x] Во время загрузки блокировать повторный Apply/Reset; объявлять успех после ответа сервера. Ошибка не показывает успешный toast и не стирает введённые условия.
- [ ] Не показывать технические имена свойств, enum ids, componentId и JSON обычному пользователю; они доступны в admin-диагностике.

## F07.2. Пресеты

- [x] Отдельные визуальные группы «Мои»/«Общие», понятный значок default и доступные действия по фактическим правам.
- [x] Длинные названия не перекрывают действия; доступны полный текст, поиск по имени и прокрутка при большом списке.
- [ ] Подтверждение удаления показывает имя/scope. Ошибка конфликта имени предлагает другое имя; version conflict предлагает обновить запись или сохранить копию.
- [x] Несовместимый preset имеет явную метку и сообщение с потерянными/неверными условиями; UI не выдаёт его за успешно применённый.
- [x] Default общих пресетов доступен менеджеру; личная копия общего редактируется независимо.

## F07.3. Доступность, темы и locale

- [ ] Клавиатура: Tab/Shift+Tab, Enter для применения, Escape для закрытия с возвратом фокуса, стрелки/Home/End в меню и списках. Не перехватывать глобально события другого экземпляра компонента.
- [ ] Роли/aria-label/aria-expanded/aria-invalid/aria-live согласованы с реальными действиями. При ошибке фокус на поле; удаление выбранного preset оставляет фокус на соседнем элементе.
- [x] Все тексты Java/Lit/default captions вынести в messages и передавать локализованный словарь из сервера; минимум имеющиеся en/ru locale аддона.
- [ ] Сохранить собственные `--rvk-filter-*` tokens; использовать проверенные токены активной темы и документированные fallback. App сейчас использует Lumo, поэтому Lumo — обязательная визуальная проверка пилота; для универсальности проверить Aura отдельно до объявления её поддержанной.
- [ ] Light/dark, ширины 360/768/1280 px, масштаб 200%, длинные русские подписи, 50+ presets, прокрутка внутри диалога, popup у нижней границы окна и два компонента на странице.

## Проверка

Скриншоты/браузерный проход обычного пользователя и менеджера, ошибок/пустого результата, клавиатуры и узкого окна. Проверять реальные production JS аддона в Jmix host; старый prototype в specs не заменяет эту проверку. `node --check` не доказывает удобство, темы или работоспособность import Lit.
