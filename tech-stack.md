# Стек технологий RVK-WS

## Платформа

- **Jmix 2.7.1** — основной фреймворк (на базе Spring Boot 3.x)
- **Java 21** (Amazon Corretto)
- **Gradle** — система сборки (composite build: модули `app`, `core`, `sso-plagin`)

## UI

- **Vaadin Flow 24.9** — серверный UI-фреймворк (через Jmix Flow UI)
- **Кастомные JS-компоненты** — Polymer-based веб-компоненты:
    - Табличные компоненты на базе **Tabulator** (tree-grid, группировка, контекстные меню)
    - Экспорт данных через **XLSX**
    - Редактор кода — **Ace Editor**
    - Просмотр PDF — **VCF PDF Viewer**
- **Vite** — сборка фронтенда, **React 18** / **Lit 3** для отдельных компонентов

## Базы данных

| БД | Назначение |
|----|-----------|
| **PostgreSQL** (схема `main`) | Основная БД приложения |
| **PostgreSQL** (схема `ws_store`, read-only) | Агрегация данных из внешних источников (NiFi загружает данные сюда) |
| **MSSQL** | Вспомогательная БД, дополнительный источник данных |
| **Elasticsearch** | Централизованное хранение логов, полнотекстовый поиск |

- **ORM**: EclipseLink (JPA)
- **Миграции**: Liquibase

## Файловое хранилище

- **MinIO** (S3-совместимое) — основное хранилище файлов и документов
- **Samba/SMB** — файловая шара для экспорта отчётов и документов

## Асинхронная обработка и задачи

- **Quartz Scheduler** (через Jmix) — фоновые задачи по расписанию (отправка уведомлений, проверки, экспорт)
- **Spring @Async** — асинхронный экспорт данных с отслеживанием прогресса
- **Temporal** — оркестрация распределённых workflow (подписание документов Diadoc, batch-обработка с retry)
- **Custom BackgroundJobService** — собственный фреймворк для длительных фоновых задач с поддержкой остановки и параллельной обработки

## Отчётность и экспорт

- **Jmix Reports** (YARG) — генерация отчётов по шаблонам (XLSX, Freemarker/Groovy)
- **Bundled-отчёты** — предустановленные отчёты: реестры ремонтов, рекламации, акты, дефектные ведомости, балансы
- **Excel-экспорт** — выгрузка данных из таблиц (синхронный и асинхронный режим с отслеживанием прогресса)
- **Кастомные отчётные компоненты** — JS-компоненты для интерактивной визуализации (tree-grid с агрегацией по периодам)

## Интеграции

- **КИХ** — интеграция с основным хранилищем данных
- **Apache NiFi** — ETL-платформа, загрузка данных из внешних источников в `ws_store`, передача данных в приложение через REST API
- **АСУ ВРК** (remontvagonov.ru) — обмен данными о ремонтах вагонов (REST/XML)
- **Diadoc** — электронный документооборот: подписание, создание и обмен документами (через связанный проект RVK-Diadoc, см. ниже)
- **Email** — SMTP-отправка уведомлений (извещения о ремонте, рекламации)

## Messaging

- **RabbitMQ** — брокер сообщений для синхронизации данных между сервисами

## Безопасность

- **Keycloak** — SSO/IAM через OpenID Connect (OIDC)
- **SSO Plugin** — собственный модуль синхронизации пользователей из OIDC-провайдера
- **RBAC** — ролевая модель доступа (Resource Roles, Entity/View/Menu policies)
- **OAuth2** — авторизация межсервисного взаимодействия (client credentials)

## Логирование и мониторинг

- **ELK Stack**: Elasticsearch + Logstash + Kibana — централизованный сбор и визуализация логов
- **Logback** + **Logstash Encoder** — структурированные JSON-логи, отправка по TCP в Logstash

## CI/CD

- **GitLab CI** — пайплайн: scan → test → build_jar → scan_SBOM → build_image → deploy → rollback
- **SonarQube** — статический анализ кода (на MR и push)
- **CycloneDX** — генерация SBOM (Software Bill of Materials)
- **Kaniko** — сборка Docker-образов в CI
- **Среды деплоя**: preprod, test, prod (с возможностью rollback)

## Инфраструктура

- **Docker** — контейнеризация (Java 21, Corretto)
- **Docker Compose** — локальное окружение (PostgreSQL, Keycloak, MinIO, Temporal, ELK)
- **Spotless** — автоформатирование кода (Palantir Java Format)

## Связанный проект: RVK-Diadoc

Отдельное Jmix-приложение для интеграции с системой электронного документооборота **Diadoc**.

- **Платформа**: Jmix 2.7.1, Java 21, PostgreSQL
- **Diadoc SDK** (SOAP-протокол) — получение событий, импорт/экспорт документов, подписание
- **Типы документов**: счета-фактуры, акты ТМЦ, ФПУ-26, УПД и другие
- **REST-сервисы** — API для основного приложения RVK-WS (через Jmix REST DataStore)
- **OAuth2 Authorization Server** — авторизация входящих запросов от RVK-WS
- **Pipeline обработки** — стратегии парсинга документов (strategy pattern), валидация, обогащение данных
- **CI/CD**: GitLab CI, SonarQube, Kaniko
