
## Функционал запуска приложение 
доработать run-app.sh таким образом чтобы он просто запускал приложение из папки где он выполняется 
тоесть [run-app.sh](../envs/remote/run-app.sh) у меня тут а запускать пусть он будет относительно этого пуст

2. если нужны какието параметры 
типа
 GRADLE_RUN_TASK=:app:bootRun
   GRADLE_TEST_TASK=:app:test
сделай отдельный .env файл в котором будут хранится основные параметры а в [.env.remote](../envs/remote/.env.remote) будет возможность
из переопределить 
мне важно чтобы если я делал отдельную папку для тестирования функционала я мог запустить проекта не переделавая параметры на 
удаленном сервере тоесть run-app.sh или run-test.sh

если запуск локально будет пусть остается как сейчас из параметров [.env.remote](../envs/remote/.env.remote)
