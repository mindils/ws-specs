# Автосогласование «как вручную»: связанные документы по настройке контрагента

## Что появилось

`/api/diadoc/approve` согласует те же документы, что и ручная кнопка «Принять», кроме
СЧФ-дополнений:
- галка «показывать связанные документы» у контрагента стоит — свои документы пакета и связанные;
- галки нет — только документы своего сообщения;
- СЧФ-дополнения и удалённые ссылки — никогда.

Раньше автосогласование брало только свои документы при любой галке.

## Как пользоваться

Ничего включать не нужно: состав определяется настройкой контрагента «показывать связанные
документы» (`diadoc_sign_settings.show_related_documents`).

## Как устроено

### Сравнение с ручным путём

| | Вручную | Автоматически |
|---|---|---|
| Согласование | «Принять» на карточке → `DiadocDocumentFlowService.approve` → `acceptDocument` | `/approve` → тот же `approve` → `acceptDocument`, пользователь «Автомат» |
| Проверки перед согласованием | только флоу (`checkCanApprove`) | флоу + настройка автосогласования + итог «Норма» + нет подписанных / отклонённых / подписываемых документов + есть свои документы |
| Документы | все строки грида: свои + СЧФ-дополнения + связанные при галке | свои + связанные при галке; без дополнений |
| Настройки подписания при согласовании | нет настройки → документ `SETTINGS_MISSING`, «не подписывать» → `SKIP`; ошибки нет | то же |
| Подписание | «Запустить подписание» → `startSigning` → `prepareForSigning` | `/sign` → тот же `startSigning`, только автосогласованный пакет в `TO_SIGN` |
| Настройки подписания при подписании | документ без настройки → ошибка `DOCUMENT_SETTINGS_MISSING`; нет настроек типа / нечего подписывать → ERROR | то же |

### В коде

- `AutoSignDecisionService.evaluate` строит список согласуемых документов (`approvedLinks`). Те же
  документы проверяются на подписанность и подписание. `AutoSignDecision.documentIds` — этот
  список.

## Как проверено

- `AutoSignDecisionIT` (21):
  - с галкой решение и `/approve` выбирают свой и связанный документы, дополнение — `USER_SKIP`;
  - без галки — только свой, связанный и дополнение — `USER_SKIP`;
  - без своих документов — по-прежнему `DOCUMENTS_NOT_FOUND`.
- `PacketFlowRestControllerTest`, `PacketCheckDisplayServiceIT`, `PacketSigningIT` — зелёные.
- Весь набор `./gradlew :app:test`: 2015 тестов, 0 падений, 12 пропущено.
- Вживую не проверялось: на 8080 и 8081 работают ваши приложения (см. 001c).

## Решено без вас

- Если своих документов нет, а связанные есть, автосогласование запрещено (`DOCUMENTS_NOT_FOUND`):
  одних связанных документов для согласования мало. Так было и раньше.

## Как шла работа

Одна сессия, ходов ritm нет, около 20 минут.

## Не сделано и ограничения

- Ручное «Принять» грузит ссылки без фильтра `deletedDate`
  (`DiadocPacketDetailView.fetchAndPrepareDocumentItems`) и может согласовать удалённую ссылку.
  Автосогласование удалённые не берёт. UI не меняли — похоже на ошибку ручного пути, решать
  отдельно.
- Сознательное отличие: ручное «Принять» согласует СЧФ-дополнения, автоматическое — нет.
