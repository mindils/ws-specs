# Замечания пользователя по UI раздела, 2026-09-16

Источник — просмотр приложения в браузере после приёмки T01–T09. Скриншоты из
чата будущим сессиям недоступны, их содержание описано текстом.

## Замечания

1. Данные скомпонованы неверно: часть полей «просто под раскрывающимся
   аккордеоном». Нужно продумать, как скомпоновать поля, чтобы было удобно.
2. Едет вёрстка: кнопки «Сохранить / OK / Отмена» карточки контейнера
   оказываются посередине формы.
3. В форме «Ремонт контейнера» вместо аккордеона сделать вкладки:
   «аккордеон вообще не удобен».
4. Документ можно не показывать постоянно, а отображать при выборе; сейчас,
   если документа нет, картинка вообще не показывается (битая).
5. Сильно играть с кастомизацией CSS не надо там, где это не нужно.
6. Почему вкладки доступны только после сохранения — можно ли обойти;
   допустимо, например, ничего не показывать; в любом случае расположить
   удобнее.

## Скриншоты (описание)

- Форма «Ремонт контейнера» на всю страницу: слева семь свёрнутых
  аккордеонов «Ремонт», «Даты и станция браковки», «Исполнитель, договор и
  гарантия», «Проверка документов», «Стоимость ремонта», «Уведомление
  завода», «Документ»; справа заголовок «Документ ремонта не загружен» и
  значок битой картинки (запрос `img/filetype/fileNotFound.png` → 403).
- Карточка контейнера: двухколоночная форма «Описание» (Дуги, Тросы, Вент.
  отверстия, Тип, Размер, Длина, массы, даты…); кнопки «Сохранить», «OK»,
  «Отмена» нарисованы поверх поля «Дата постройки», ниже — текст «Сохраните
  описание — после этого станут доступны вкладки контейнера».

## Решения пользователя (AskUserQuestion, 2026-09-16)

- Карточка контейнера: «Описание» — первая вкладка tabSheet; у нового
  контейнера остальные вкладки неактивны до первого сохранения; без
  аккордеона и без текста-подсказки; кнопки всегда внизу.
- Форма ремонта: 5 вкладок — «Ремонт», «Исполнитель и договор», «Документы и
  стоимость», «Уведомление завода», «Документ».
- Просмотр документа — только когда файл есть (в формах после загрузки, во
  вкладке «Файлы» при выборе строки с файлом); заглушек с картинкой нет.
- 403 на `/img/**` чинится в этой работе отдельным маленьким таском.
