# Инструкция по внесению записей в ЕРК (извлечение из docx)

Источник: [Инструкция по внесению записей в ЕРК.docx](Инструкция%20по%20внесению%20записей%20в%20ЕРК.docx),
редакция 05.08.2026. Ниже — текст документа и описание его 13 скриншотов,
чтобы будущим сессиям не требовалось разбирать docx. Это описание поведения
старой системы; при расхождении действуют решения [plan.md](../plan.md).

## Как операторы работают

Все сценарии начинаются с самостоятельной страницы списка («Ремонт
контейнеров», «Прикрепленные файлы», «Реестр контейнеров»), а не с карточки
контейнера. Действия: «Добавить запись» → заполнить поля → «Создать и перейти
в таблицу»; либо найти контейнер в поиске списка → меню строки → «Редактировать»
→ «Сохранить». В новой системе «Прикрепленные файлы» заполняются во вкладке
карточки контейнера, остальное — как в инструкции (решение пользователя).

## 1. Тех. обслуживание «Альфа Логистика»

Ремонт: номер контейнера; вид ремонта «Техническое обслуживание»; причина
неисправности «эксплуатационная»; комментарий при необходимости; дата
браковки = дата акта осмотра; станция браковки = станция из акта осмотра; дата
отправления в ремонт и дата начала ремонта = дата акта осмотра; дата окончания
ремонта = дата акта выполненных работ или дата начала + 3 дня; исполнитель
«АЛЬФА ЛОГИСТИКА (ФГК)»; договор на ремонт «ФГК-378-13»; станция ремонта =
станция из акта осмотра. Примеры ИД: 786057, 786059.

Файл: номер контейнера; вид файла «Документ к техническому обслуживанию»;
комментарий «Акт осмотра от __.__.____ Бронка»; файл. Примеры ИД: 786063,
786064.

## 2. Прислали инструкцию

Ремонт: вид «Текущий ремонт»; причина «технологическая»; неисправность из
ранее высланного акта осмотра; комментарий («Модернизация», «После
модернизации», уточнения через точку); дата браковки и станция браковки из
акта осмотра; дата отправления в ремонт = дата ТТН ввоз; «Ремонт выполнен по
гарантии» — выбор условия гарантии по договору (договор 47-15 → 385331,
договор 79-9 → 786974 (Ремонт) и 786975 (ТО)); дата уведомления завода = дата
письма «О вывозе контейнера в ремонт»; станция ремонта по инструкции = станция
из инструкции; дата получения ответа = дата инструкции. Примеры ИД: 617034,
786054.

Файл: вид «Документ к ремонту»; комментарий «Инструкция в ремонт №__ от
__.__.____ (площадка)». Пример ИД: 598966.

## 3. Прислали акт выполненных работ

Редактирование существующего ремонта: дата отправления в ремонт (если не было);
дата начала и дата окончания ремонта = дата АВР; исполнитель из АВР; договор
на ремонт «ФГК-47-15» (у ООО «АВРОРА» другой договор — см. раздел 5); «На
ремонт действует гарантия» — выбор условия по договору (те же ИД); станция
ремонта из АВР. Пример ИД: 779700.

Файл: вид «Документ к ремонту»; комментарий «Акт выполненных работ №__ от
__.__.____ (площадка)». Пример ИД: 779879.

## 4. Прислали акт периодического освидетельствования

Реестр контейнеров: найти контейнер → «Редактировать» → галочка «Модернизация
крыши», «Дата модернизации крыши» = дата акта. Пример: FGKU5023220.

Файл: вид «Документ к ремонту»; комментарий «Акт периодического
освидетельствования РМРС». Пример ИД: 783812.

## 5. Прислали ТТН (ввоз/вывоз)

Ремонт: дата отправления в ремонт = дата ТТН ввоз; дата возврата из ремонта =
дата ТТН вывоз. Пример ИД: 755567.

Файл: вид «Документ к ремонту»; комментарий «ТТН ВВОЗ/ВЫВОЗ (площадка)»;
поле «Имя файла» = «ТТН от __.__.____». Примеры ИД: 786006, 786011.

## 6. Документы от ООО «АВРОРА» (АВР, счёт-фактура, дефектные ведомости, ТТН)

Ремонт: вид «Текущий ремонт»; причина «эксплуатационная»; неисправность;
комментарий; дата и станция браковки; дата отправления = ТТН ввоз; дата начала
и окончания = дата АВР; дата возврата = ТТН вывоз; исполнитель «АВРОРА ООО
(ФГК)»; договор «ФГК-79-9»; «На ремонт действует гарантия» при гарантийном
ремонте; дата представления и дата проверки документов; результат проверки
«принято» (иначе причина отклонения); стоимость без НДС, НДС (%) = 22, НДС
(руб.), стоимость с НДС — из счёта-фактуры; дата уведомления завода = дата
заявки; станция ремонта по инструкции; дата получения ответа; станция ремонта
из АВР. Пример ИД: 755098.

Файлы: вид «Документ к ремонту»; комментарии «Акт осмотра … // Заявка в ремонт
… // УПД … // Акт выполненных работ …»; для ТТН — «Имя файла» = «ТТН от
__.__.____». Примеры ИД: 755101, 755103, 755106, 755540.

Выводы для новой системы: «Имя файла» — отдельное ручное поле; условие

собственник — организации из НСИ с суффиксом «(ФГК)»; «Дата браковки»
обязательна на уровне формы.
