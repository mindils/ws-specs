Зависимости: [T03](../T03/task.md), [T06](../T06/task.md)

Актуальная проверка: [checks/001.md](checks/001.md)

## Коротко

Делаем страницу «Ремонты контейнеров» (главный рабочий экран операторов по
инструкции) и вкладку «Ремонты» в карточке, а также вкладку «Акты» карточки с
привязкой общих актов. Форма ремонта содержит все поля старой системы: даты,
станции, неисправность, договор, два условия гарантии, стоимости и один
документ.

## Результат и контекст

Сценарии операторов 1–6 — [instruction-erk.md](../../input/instruction-erk.md);
скриншот списка — [img_1.png](../../input/img_1.png). Поля — `cnt_repair` в
[contracts.md](../../contracts.md); обязательные в UI — контейнер и дата
браковки; подписи гарантий содержат id; поведение вкладки «Акты» — раздел
«Карточка контейнера и вкладки». Формы договора/условия/акта — T06.

## Область и изоляция

Меняет: `container/view/containerrepair/` (list, detail),
`container/view/fragment/{containerrepair,containeract}/`, вкладки в XML
карточки T03 (добавление своих `<tab>`), сервис unlink/delete акта в
`container/service` (если не сделан в T06), политики (добавление), `menu.xml`
(пункт), messages, тесты. Общие ресурсы: БД, порт 8080, браузер, MinIO.
Параллельно с T04. Проверки после T04.

## Реализация

- Skills: `jmix-create-list-view`, `jmix-create-detail-view`,
  `jmix-create-fragment`, `jmix-add-dialog-detail-flow`, `jmix-create-service`,
  `jmix-configure-fetch-plan`, `jmix-add-i18n-keys`, `jmix-create-resource-role`,
  `jmix-create-test`.
- Список ремонтов: колонки id, документ, контейнер, вид, исполнитель, договор,
  даты браковки/начала/окончания и остальные по матрице через настройку
  колонок; фильтры по contracts.md; экспорт; создать/редактировать/
  копировать/удалить.
- Detail: группы полей — контейнер (lookup по номеру, из вкладки
  предустановлен); вид/причина/неисправность/комментарий; дата и станция
  браковки; даты отправления/начала/окончания/возврата; исполнитель
  (`VOrgPassport`), договор (`entityComboBox` + `entity_lookup` на
  `cnt_ContainerContract.list`), «Ремонт выполнен по гарантии» и «На ремонт
  действует гарантия» — два независимых lookup `cnt_ContainerWarranty.list`;
  документы (даты представления/проверки, результат, причина отклонения);
  стоимости без НДС / НДС % / НДС руб. / с НДС — ручные; уведомления завода
  (даты, станция по инструкции, дата ответа, дата повторного уведомления);
  станция ремонта; модернизация крыши; документ `FileRef` с просмотром.
  Никаких расчётов и изменения контейнера.
- Вкладка «Ремонты» — фрагмент по контракту T03. Вкладка «Акты» — фрагмент с
  гридом актов контейнера (через `cnt_act_container`) и действиями «Создать»
  (форма акта T06 с текущим контейнером в составе), «Добавить существующий»
  (lookup `cnt_ContainerAct.list`, связь без дубля), «Убрать из контейнера»
  (только связь), «Удалить акт» (soft delete акта и всех его связей одной
  транзакцией; диалог подтверждения перечисляет другие контейнеры акта).
- Политики: `cnt_ContainerRepair.list/detail`, menu, атрибуты; для вкладок —
  уже существующие view-id T06.

## Критерии приёмки

- C1: Сценарий 1 инструкции (ТО «Альфа Логистика») воспроизводится из списка
  ремонтов: все указанные поля сохраняются, «Дата браковки» обязательна,
  договор и станции выбираются lookup-ом.
- C2: Сценарий 6 (АВРОРА) сохраняет стоимости 31479.65 / 22 / 6925.52 /
  38405.17 буквально; два условия гарантии выбираются независимо; три станции
  независимы; «Модернизация крыши» ремонта не меняет контейнер.
- C3: Ремонт, созданный из вкладки, предзаполняет контейнер; из списка —
  контейнер выбирается по части номера; запись видна в обеих точках входа.
- C4: Акт A+B создан из вкладки A, виден во вкладке B; «Убрать из контейнера»
  в A оставляет акт у B; «Добавить существующий» в A возвращает связь без
  дубля; «Удалить акт» удаляет акт и связи, контейнеры остаются; cancel
  формы акта не оставляет частичных связей.
- C5: Документ ремонта загружается/заменяется/скачивается; копия ремонта без
  документа.
- C6: Удаление контейнера с ремонтом или связью акта отклоняется; удаление
  используемого договора/условия/справочника отклоняется.
- C7: Роль read только просматривает; edit имеет все политики; экспорт списка
  ремонтов учитывает фильтры.
