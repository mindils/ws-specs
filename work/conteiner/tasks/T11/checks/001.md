## Ошибки и непроверенное

Подтверждённых ошибок нет, файл исправления не создавался.

Расхождение в постановке (не дефект реализации): C4 говорит про 22 поля
описания, фактически их 21. Перечень полей в самом таске, таблица раздела
«Карточка контейнера (T11)» в [contracts.md](../../../contracts.md) и прежний
XML дают одно и то же число 4 + 9 + 4 + 4 = 21. Реализация перечню
соответствует полностью, поэтому C4 засчитан; число в тексте критерия
проверяющим не правится — исправление формулировки уместно при закрытии
работы.

Ограничения окружения, зафиксированные фактически, а не обойдённые:

- `ownerField` заполнить нечем: `main_rvk_ws.nsi_v_org_passport` содержит
  0 строк, поиск по подстроке в lookup возвращает пустой список. Это
  известное свойство локальной схемы (plan.md, раздел «Параллельность и
  тестирование»), а не поведение карточки.
- IDE-инспекция `*-view.xml` недоступна: в сессии нет JetBrains MCP. Замена —
  механическая проверка дескриптора (раздел 1) плюс фактическая проверка всех
  привязок в браузере (раздел 6); покрытие по нерезолвящимся `msg://`,
  property path и data container достигнуто, семантику вне этих трёх классов
  замена не закрывает.
- В MinIO остался объект загруженного проверочного файла
  (`cnt_file/2026/09/16/…txt`) — строка `cnt_container_file` удалена, сам
  объект в бакете `rvk-dev` не подчищался.
