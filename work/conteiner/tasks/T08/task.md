  системе; операций/накладных и истории снимков нет.
- C4: Soft delete, запреты удаления, уникальность номера, копирование, отмена

  изменённому файлу; нет необъяснённых пропусков.
- C6: Браузерный проход без error overlay, серверных исключений, сырых
  `msg://`, недоступных по ошибке полей.

## Независимая проверка

Инфраструктура и гейты по plan.md, `./gradlew :app:test`, затем `playwright-cli`
последовательно:

1. Под НСИ-ролью: убедиться, что справочники наполнены (T10); добавить одну
   модель и один вид характеристики; выбрать существующие станции.
2. Под edit: на реестре создать контейнеры A и B с разными следующими датами;
   проверить виртуальные поля модели/типа/размера.
3. Характеристика и PDF-файл у A; освидетельствование из отдельной страницы,
   открыть из A, заменить акт; следующая дата A не изменилась.
4. Ремонт A по сценарию 6 инструкции с договором «ФГК-79-9» и условием
   786974; ремонт из вкладки A; акт A+B из вкладки A; проверить вкладки B.
5. Переименовать A — связи сохранились; копия A с новым номером без детей;
   дубль номера отклонён.
6. Заменить документ ремонта; во вкладке «История» A видны CREATE/MODIFY;
   изменить справочник — старые записи журнала не изменились; отменить формы
   — новых записей нет.
7. Убрать A из акта — акт остался у B; вернуть через «Добавить существующий»;
   попытка удалить A, используемый договор, условие и справочник — отклонены.
8. Удалить дочерние записи A, затем A; A исчез из списков; повторный номер A
   отклонён; в `entityLog.view` есть DELETE.
9. Под read: просмотр, поиск, фильтры, колонки, экспорт, скачивание; изменения
   недоступны, прямые URL режима edit не дают сохранить; НСИ-роль без edit не
   меняет основные записи.
10. Проверить сообщения, консоль, серверный лог; убрать тестовые данные, не
    трогая начальные данные T10.

Тесты и браузер строго последовательно; отчёт указывает, кто выполнял проход,
роли, команды, состояние кода. Без браузера — `render not browser-verified`,
C2 и C6 не выполнены.
