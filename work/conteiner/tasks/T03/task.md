## Коротко

Делаем страницу «Реестр контейнеров» и карточку контейнера с вкладками
Описание, Характеристики, Файлы и История; вкладки Ремонты,
Освидетельствования и Акты подключат T07 и T04 по контракту этого таска.
Редактор сможет вручную создать контейнер на пустом реестре, заполнить его
характеристики и приложить файлы с просмотром PDF.

Контейнеров в РВК нет; реестр заполняется вручную. Скриншоты:

[форма файла](../../input/img_4.png), сценарии файлов —
[instruction-erk.md](../../input/instruction-erk.md). Контракты: разделы

## Область и изоляция

Меняет: `container/view/container/` (list, detail), `container/view/fragment/
{containerproperty,containerfile}/`, детали характеристики и файла (диалоги),
`container/service` (при необходимости), политики в `container/security`
(добавление view-id и атрибутов), `menu.xml` (пункт `cnt_Container.list`),
`application.properties` (`rvk.storage-folders.cnt-file`), messages, тесты.

Общие ресурсы: БД, порт 8080, браузер, MinIO (локальный из compose).
Параллельно с T06. Проверки после T10 в порядке плана.

## Критерии приёмки

- C1: Реестр открывается из меню «Контейнеры»; на пустом реестре редактор
  создаёт контейнер со всеми полями и НСИ; после сохранения контейнер
  находится в списке и в lookup по номеру.
- C2: Модель показывает четыре количества, размер — длину в футах, тип —
  название; смена lookup обновляет отображение, ручные поля не меняются.
- C3: Номер ` fgku5026002 ` сохраняется как `FGKU5026002`; повтор номера даёт
  понятную ошибку без потери формы.
- C4: Характеристика и файл создаются из вкладок только у сохранённого
  контейнера; отмена диалога ничего не сохраняет; после SAVE грид обновлён.
- C5: PDF загружается, отображается в просмотре и скачивается; замена файла
  сохраняет запись с новым файлом; «Имя файла» — ручное поле.
- C6: Копия контейнера открывается без номера, детей, файлов; удаление
  контейнера с характеристикой/файлом отклоняется с сообщением, после их
  удаления — проходит (soft delete, запись исчезает из списка).
- C7: Вкладка «История» показывает записи CREATE/MODIFY по контейнеру.
- C8: Роль read открывает реестр и карточку только на просмотр (кнопки
  недоступны, прямой URL не даёт сохранить); экспорт учитывает фильтры.
- C9: В contracts.md записан рабочий контракт подключения вкладок.

`:app:test` и полный браузерный проход — проверяющему.
