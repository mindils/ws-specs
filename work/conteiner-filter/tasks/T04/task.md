- C1: `./gradlew :app:test --tests 'ru.fgk.ws.app.container.*' --tests 'ru.fgk.ws.app.security.UiMinimalRoleTest'` зелёный.
- C2: `./gradlew spotlessCheckAll` — BUILD SUCCESSFUL.
- C3: под `user_read` все 19 страниц открываются, поиск и условия
  фильтруют, личный пресет сохраняется и выбирается после переоткрытия; под
  `user_nsi` пресет сохраняется на справочнике; 0 `ERROR` в логе, сырых
  `msg://` нет.
- C4: `grep -rn 'ListView.filter\.' messages_ru.properties` для контейнерных
  view показывает только ключи, на которые ссылаются XML.

## Независимая проверка

- Те же команды на состоянии, зафиксированном в `result.md` (commit или
  список файлов).
- Браузер (`bootRun` в фоне, `/actuator/health` UP, `playwright-cli`,
  `/local-login`): под `user_read` — реестр (поиск, условие по дате
  следующего освидетельствования, выпадающий список модели + поиск, Reset,
  пресет), ремонты (поиск по номеру контейнера, вид ремонта из списка),
  освидетельствования, акты, договоры, гарантии («ИД»), два справочника; под
  `user_nsi` — справочник с пресетом; под `user_edit` — создание ремонта из
  списка с работающим lookup контейнера. Проверить отсутствие 403/500 и
  сырых `msg://`; погасить только свой процесс.
- Отчёт фиксирует изоляцию (схема, порт) и порядок занятия ресурсов.
