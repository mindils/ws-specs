## Коротко

Показать новый результат проверки пользователю: окно нарушений с блоком автоподписания на
карточке пакета и колонку «Корректный пакет» в списке. Правила — план, раздел «Экраны».

## Что сделать

- `DiadocPacketDetailView`: кнопка результата проверки (сейчас `showCheckResultButton` +
  текстовое окно) — статус по строке `packet_check`; окно с таблицей позиций (источник, уровень,
  текст) и блоком автоподписания из сервиса t04 (расчёт без сохранения). Пакет без строки — позиции
  `DIADOC` на лету; у СЧФ блока автоподписания нет.
- `DiadocPacketListView`, колонка «Корректный пакет»: по строке `packet_check`, без строки — флаги
  Диадок на лету (как сейчас в `DiadocPacketCheckResultService.displayedCorrectPacket`). Строки
  грузить пачкой на отображаемые пакеты, не запросом на строку.
- Весь текст через messages. Скилы: `jmix-add-i18n-keys`, `jmix-style-ui`,
  `jmix-configure-fetch-plan`. Иконки — только реальные `VaadinIcon`.

Не трогать: остальные экраны (ВУ-23, Рем.Дет, ТР-1, рекламации) и кнопки согласования.

## Готово, когда

- На карточке наработанного пакета видны позиции всех источников с уровнями и решение по
  автоподписанию с причинами.
- Колонка списка совпадает со строкой `packet_check`; для СЧФ — как раньше.

## Как себя проверить

- `DiadocPacketListViewTest` — обновить; тест/UI-тест на окно карточки по образцу `BaseUiTest`,
  если реально его поднять.
- Инспекция изменённых `*-view.xml` по `jmix-ide-static-analysis`.
- Весь набор `./gradlew :app:test` зелёный. Браузер — в приёмке.
