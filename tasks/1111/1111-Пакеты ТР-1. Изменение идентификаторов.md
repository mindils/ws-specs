Необходимо перекинуть идентификаторы на новые поля в БД и в Entities одновременно.

Поля таблиц message_id и parent_message_id заполненяются. Лишние записи в таблицах почистила.

Таблица dr_diadoc_oper_repair_tr1 - заголовок Акта.

Таблица dr_diadoc_oper_repair_tr1_wag - список вагонов.

Необходимо убрать из заголовочной таблицы поле id (сейчас это PrimaryKey) сделать идентификатором поле parent_message_id и список вагонов привязать к заголовку по новому идентификатору, полю parent_message_id.

MessageId в вагонах можно удалить, чтобы избежать путаницы и хранить его только в заголовочной таблице. При каждой последующей корректировке пакета с любым MessageId сохранять запись только с одним ParentMessageId (если запись первичная для ParentMessageId, в таблице будет совпадение с MessageId).
