Изменение ключей в таблице: PtRepairPacket сейчас поле id = messageId и является идентификатором таблицы, необходимо сделать идентификатором поле parentMessageId, при наработке пакета (сервис RemDetParserService) и рядом поле messageId, по которому будет отображаться актуальный пакет Diadoc из контекстного меню (parentMessageId должен быть задействован только в разборе пакета для перезаписи корректировочного пакета и для связи группы таблиц ptRepairPacket\_). В MessageId записываем самый последний (обработанный) корректировочный идентификатор пакета, ParentMessageId при этом сохраняется и на него должны ссылаться дочерние таблицы (PtRepairPacketMh, PtRepairPacketMhScrap, PtRepairPacketWork, PtRepairPacketUserData - сейчас у них ссылка на ptRepairPacket.id записи PtRepairPacket для одного ParentMessageid не уникальны). Дублирование строк по ParentMessageId нужно вычистить, одна строка для одного ParentMessageId. При этом важно сохранить данные ptRepairPacketUserData – существующие пользовательские данные к пакетам.
